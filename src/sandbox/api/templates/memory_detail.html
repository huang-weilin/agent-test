快照是内容寻址的：摘要相同即内容相同。所以「与上一个相同」 是个确定的判断——它说明那个边界的记忆一个字节都没变， 拿它去恢复是个空操作，不该被当成故障注入。反过来，摘要不同也不代表内容有意义， 只是说字节确实不同。

这里看不到记忆条目本身的内容，只能看到条数和大小。 内容是 adapter 私有的格式（Hermes 是 JSONL、LangGraph 是 checkpointer 的 序列化格式），由 MemoryAdapter 负责读写。在视图层解析它， 等于把界面绑死在一种记忆载体上——换一个适配器，这一页就得重写。
