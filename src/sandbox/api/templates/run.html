记忆视野是跨会话归因的唯一依据：这个会话开始时，Agent 的记忆 覆盖到哪个序号为止。自然延续等于"记得此前一切"；从旧快照恢复时会比 ordinal - 1 小，缺的那一段就是它不可能知道的部分。 于是"是谁的锅"不需要猜——某次调用发生在序号 a、又在序号 b 重复， a ≤ 视野(b) 就是 Agent 本可以知道，否则是记忆恢复机制的锅。

熔断时脚本必然没消费完，但那不算前提不成立。 循环场景的预期结果就是被熔断：检测器判出来了、看门狗动手了，说明想制造的行为 确实发生了。不豁免的话，一个完美触发的循环场景会被报成"没测到"。
